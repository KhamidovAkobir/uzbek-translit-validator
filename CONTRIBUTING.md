# Contributing to uzbek-translit-validator

Thank you for your interest in improving the Uzbek localization and validation ecosystem!

## How to Contribute
1. Fork the repository and create your feature branch (`git checkout -b feat/new-rule`).
2. Add your changes in the `src/` directory (e.g., adding morphological exceptions to `src/dictionary.js`).
3. Ensure all existing and new unit tests pass via `npm test`.
4. Submit a Pull Request with clear examples of the linguistic or validation edge cases solved.
